# 自定义资产

CARLA默认提供了丰富的资产，包括完整的城镇道路网络、建筑基础设施、车辆和行人等。但对于特殊应用场景，用户可以完全自主创建新资产并加载到CARLA中，实现最大程度的扩展性。

以下文档详细说明了创建自定义资产并将其添加到CARLA的多种技术方案：

- [__添加道具__](tuto_A_add_props.md)
- [__添加车辆__](tuto_A_add_vehicle.md)
- [__资产打包__](tuto_A_create_standalone.md)
- [__材质定制__](tuto_A_material_customization.md)

## [添加道具](tuto_A_add_props.md)

道具是场景中除道路和车辆外的其他资产，包含路灯、建筑物、树木等。模拟器可以通过简单流程随时导入新道具，这对创建定制化地图环境非常有用。[__本文档__](tuto_A_add_props.md)演示了如何创建并集成自定义道具。

## 添加车辆

车辆是CARLA的核心要素，既用于模拟其他道路使用者，也可作为自动驾驶代理控制的虚拟仿真对象。尽管CARLA已内置大量车辆资源，但对于特殊需求仍支持加载自定义设计的车辆。[__本文档__](tuto_A_add_vehicle.md)详细说明了如何创建并导入自定义车辆。

## 资产打包

在CARLA中，使用独立资源包（standalone packages）管理资产是常见做法。这种方式可以有效控制构建包体积，并支持随时将资产包导入CARLA项目。该方法也为有序分发资产提供了便利。[__本文档__](tuto_A_create_standalone.md)演示了如何打包资产以供CARLA使用。

## 定制材质

CARLA团队为所有资产预设了默认运行参数，但源码构建用户可根据需求修改这些设置。[__本文档__](tuto_A_material_customization.md)演示了如何实现材质定制。
