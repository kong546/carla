# 城镇10

![城镇10幻灯片](../img/catalogue/maps/town10/town10montage.webp)

城镇10融合了市中心环境特征，包含玻璃幕墙摩天大楼、工业建筑、滨海步行道、公寓楼群、酒店、公共建筑以及林荫大道。其道路网络包含多种交叉口布局，具备多样化的车道标线、人行横道和交通信号类型，为自动驾驶系统提供复杂交通场景挑战。

## 道路网络

采用网格状道路布局，包含多种交叉口类型：四向黄色网格线交叉口、专用转向车道及中央隔离带。

![城镇10道路网络](../img/catalogue/maps/town10/town10roadnetwork.png)

## 商业综合体摩天大楼

天际线由多栋摩天大楼组成，底层配置商业单元。

![城镇10摩天大楼](../img/catalogue/maps/town10/town10skyscrapers.webp)

## 热带植被林荫大道

街道两侧种植热带植被形成特色林荫景观带。

![城镇10林荫大道](../img/catalogue/maps/town10/town10treeboulevard.png)

## 古典风格公共建筑

包含博物馆等采用古典建筑风格的公共设施。

![城镇10博物馆](../img/catalogue/maps/town10/town10museum.png)

## 北美风格联排住宅

街道两侧分布北美城市典型联排住宅及配套巷道系统。

![城镇10联排住宅](../img/catalogue/maps/town10/town10townhouses.webp)
