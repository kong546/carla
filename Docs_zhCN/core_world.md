## 客户端

客户端是CARLA架构的核心组件，通过脚本与服务器建立连接、获取信息并发出操作指令。每个客户端通过IP和端口进行身份验证后，即可连接世界并控制仿真。

```py
# 创建客户端并设置超时
client = carla.Client('localhost', 2000)
client.set_timeout(10.0)  # 单位：秒
```
