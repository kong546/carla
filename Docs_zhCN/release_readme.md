如何运行 CARLA
----------------

在本目录中打开终端，通过以下命令启动模拟器：

```sh
./CarlaUnreal.sh
```

这将打开一个包含城市景观的窗口。这是"观察者视角"，您可以使用鼠标和WASD键在城中飞行，但无法在此视角下与世界互动。此时模拟器已作为服务器运行，等待客户端连接交互。

让我们为城市增添生机，请打开新的终端窗口并执行：

```sh
./generate_traffic.py -n 80
```

这将在世界中添加80辆处于"自动驾驶"模式的车辆。返回模拟器窗口即可看到这些车辆在城市中行驶。它们将保持随机行驶直到脚本停止。

现在CARLA中阳光明媚，但这并不是最有趣的驾驶条件。CARLA的亮点功能之一是可以通过脚本动态控制天气和昼夜变化，请打开另一个终端窗口执行：

```sh
./dynamic_weather.py
```

城市现已准备就绪，最后运行：

```sh
./manual_control.py
```

这将打开包含车辆第三人称视角的新窗口，您可以使用WASD/方向键驾驶。按'h'键查看所有可用选项。

更多详细信息和运行选项请参考在线文档：

<http://carla.readthedocs.io>
