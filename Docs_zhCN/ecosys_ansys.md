# Ansys实时雷达模型：使用强化学习训练车辆纵向控制器

在2021年4月的网络研讨会系列中，[Ansys](https://www.ansys.com/)详细介绍了其Ansys实时雷达(RTR)与CARLA模拟器的集成。您可以在此下载并查看研讨会相关的演示文稿和视频。

演示文稿详细说明了RTR如何与CARLA集成，用于通过强化学习训练车辆纵向控制器，包含使用的模型、动作空间和奖励策略。视频展示了在CARLA模拟器中的训练结果。
