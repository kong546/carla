## 1- 二进制字符串

字符串采用长度前缀编码，首字节为字符串长度（无终止符）。例如字符串'Town06'的十六进制表示为：06 00 54 6f 77 6e 30 36

![二进制动态字符串](img/RecorderString.jpg)

## 2- 信息头

信息头包含记录文件的通用信息：版本号、魔数字符串（用于文件识别）、1900年以来的时间戳秒数，以及记录使用的地图名称。

## 3- 数据包

每个数据包以5字节头开始：

![数据包头](img/RecorderPacketHeader.jpg)

* **id**: 数据包类型
* **size**: 数据部分大小

头部后跟随**数据**部分（size为0时表示无数据）。通过包头可跳过不感兴趣的数据包，直接定位到下一个数据包。

![数据包尺寸](img/RecorderPackets.jpg)

当前支持的数据包类型：

![数据包类型列表](img/RecorderPacketsList.jpg)

建议用户自定义数据包使用100以上的id值。

### 数据包0 - 帧开始

标记新帧开始，每个帧的第一个数据包。所有数据包必须位于帧开始和帧结束之间。

![帧开始](img/RecorderFrameStart.jpg)

elapsed + durationThis = 下一帧的累计时间

### 数据包1 - 帧结束

无数据负载，标记当前帧结束。帮助回放系统识别帧边界。

![帧结束](img/RecorderFrameEnd.jpg)

### 数据包2 - 添加事件

声明当前帧需要创建的演员数量。

![添加事件](img/RecorderEventAdd.jpg)

**total**字段表示后续记录数。每条记录包含：
- **id**: 记录时的演员ID
- **type**: 演员类型：
  * 0 = 其他
  * 1 = 车辆
  * 2 = 行人
  * 3 = 交通信号灯
  * 4 = 无效
- **location**/**rotation**: 生成坐标
- **description**: 演员描述（uid为数字ID，id为文本ID如'vehicle.seat.leon'）
- **attributes**: 属性集合（颜色、车轮数、角色等）

### 数据包3 - 删除事件

声明当前帧需要销毁的演员数量。

![删除事件](img/RecorderEventDel.jpg)

**total**字段表示记录数，每条记录为要删除的演员ID。

### 数据包4 - 父级事件

声明演员父子关系。

![父级事件](img/RecorderEventParent.jpg)

第一个ID为子演员，第二个为父演员。

### 数据包5 - 碰撞事件

记录两个演员之间的碰撞事件（仅带有碰撞传感器的演员会报告）。

![碰撞事件](img/RecorderCollision.jpg)

**id**用于内部标识碰撞序列，同一演员对可能在单帧内发生多次碰撞。

### 数据包6 - 位置信息

记录场景中所有车辆和行人的位置与朝向。

![位置信息](img/RecorderPosition.jpg)

### 数据包7 - 交通信号灯

记录所有交通信号灯的状态（红/黄/绿）及状态切换倒计时。

![信号灯状态](img/RecorderTrafficLight.png)

### 数据包8 - 车辆动画

记录车辆动画参数：油门、转向、刹车、手刹和档位。

![车辆状态](img/RecorderVehicle.jpg)

### 数据包9 - 行人动画

记录行人动画速度参数。

![行人状态](img/RecorderWalker.jpg)

---
## 4- 帧结构

帧由多个数据包组成，必须包含帧开始和结束数据包。事件数据包仅在发生帧有效，位置和交通信号灯数据包建议每帧包含。

![帧布局](img/RecorderFrameLayout.jpg)

---
## 5- 文件结构

文件以信息头开始，后接按帧分组的数据包集合。每组以帧开始数据包起始，以帧结束数据包终止。

![文件布局](img/RecorderLayout.jpg)

典型结构优先排列事件数据包，随后是位置和状态数据包：

![布局示例](img/RecorderLayoutSample.jpg)

* 帧1：演员创建与父子关系
* 帧3：碰撞事件发生
* 帧4：演员销毁
