# 自定义地图

在CARLA中，地图包含城镇的3D模型及其道路网络定义。道路网络通过[__OpenDRIVE__](https://www.asam.net/standards/detail/opendrive/)标准进行描述。CARLA提供多种开箱即用的地图，同时用户也可创建自定义地图并加载到CARLA中。以下教程详细说明了创建和加载自定义地图到CARLA的具体步骤：

* [__添加地图包__](tuto_M_add_map_package_zhCN.md)
